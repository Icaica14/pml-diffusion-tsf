# CHE_COSA_SONO — docs/presentation

> Tutto il materiale per la **presentazione orale** (~8 minuti) sul dataset Electricity,
> in italiano: mappa delle figure, copione, struttura slide, Q&A e numeri di riferimento.

| File | Che cos'è |
|---|---|
| `FIGURE_PLAN_ELECTRICITY_IT.md` | Mappa di **tutte** le figure della presentazione: per ciascuna cosa mostra, perché serve, da quali dati nasce, se esiste già o va generata e con quale script. |
| `SLIDE_TEMPLATE_ELECTRICITY_IT.md` | La struttura, slide per slide, della presentazione. |
| `SPEAKER_SCRIPT_8_MIN_IT.md` | Il copione parlato, a tempo (8 minuti), per l'orale. |
| `QA_ORALE_ELECTRICITY_IT.md` | Domande probabili della commissione + risposte preparate. |
| `RESULTS_PLACEHOLDERS_ELECTRICITY.md` | Numeri di riferimento di M3 (CRPS/MASE/coperture/tempi): nati come placeholder durante il run, ora con i **valori reali** di TimeGrad. |
| `NEXT_PROMPT_AFTER_M3_IT.md` | Promemoria operativo: cosa fare appena il run M3 finisce (rigenerare tabelle e figure). |
| `SWEEPS_E2_E3_IT.md` | Come si lanciano e si **leggono** gli sweep **E2** (orizzonte τ) ed **E3** (passi di denoising), sia in locale sia su Colab. |
